# Campus Board - Renderizacao Segura de Conteudo

Miniaplicacao Node.js/Express usada em atividade pratica sobre renderizacao segura de conteudo e mitigacao de Cross-Site Scripting (XSS).

A aplicacao simula um mural interno com busca, mensagens, perfil de visitante e sessao. A versao vulneravel foi usada para demonstrar XSS refletido, XSS armazenado, DOM-based XSS e cookie acessivel por JavaScript. A versao corrigida aplica sanitizacao com DOMPurify, Content Security Policy, protecao de cookies e correcoes de renderizacao.

## Branches

- main: versao segura/corrigida.
- app-vulneravel-bonito: versao vulneravel usada para evidencias antes das correcoes.

## Como executar

Instale as dependencias:

    npm install

Execute a aplicacao:

    npm run start

A aplicacao ficara disponivel em:

    http://localhost:8080

## Funcionalidades da aplicacao

- Pagina inicial do Campus Board.
- Mural de mensagens.
- Busca de avisos.
- Perfil de visitante com nome definido via hash da URL.
- Pagina de conta com criacao de sessao.

## Vulnerabilidades demonstradas na versao vulneravel

Na branch app-vulneravel-bonito, foram demonstradas as seguintes fragilidades:

- XSS refletido na pagina de busca.
- XSS armazenado no mural de mensagens.
- DOM-based XSS na pagina de perfil.
- Cookie de sessao acessivel via document.cookie.
- Ausencia de Content Security Policy restritiva.

## Mitigacoes implementadas na versao segura

Na branch main, foram aplicadas as seguintes correcoes:

- Sanitizacao de HTML no mural com DOMPurify.sanitize().
- Codificacao de saida na pagina de busca.
- Substituicao de innerHTML por textContent no perfil.
- Content Security Policy com script-src self.
- Cookie de sessao com HttpOnly e SameSite=Lax.
- Cabecalhos de seguranca via Helmet.
- Token Anti-CSRF no formulario de mensagens.
- Remocao do cabecalho X-Powered-By.
- Uso de X-Content-Type-Options: nosniff.

## Payloads utilizados

XSS refletido:

    <script>alert(1)</script>

XSS armazenado:

    <img src=x onerror=alert(1)>

DOM-based XSS:

    <img src=x onerror=alert(1)>

Teste de exposicao de cookie:

    document.cookie

## Observacoes

O ambiente foi executado localmente em http://localhost:8080. Os testes com OWASP ZAP foram realizados somente contra a aplicacao local, em ambiente autorizado.

A versao segura mitiga os payloads testados e adiciona camadas de protecao, mas nao deve ser interpretada como uma aplicacao de producao completa.
